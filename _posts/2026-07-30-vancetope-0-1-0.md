# Vancetope 0.1.0 is out 🎉

It's tagged, it's pushed, it's real: **[Vancetope 0.1.0](https://github.com/mhus/vance/releases/tag/v0.1.0)** — the very first release.

I'll be honest, because honesty is the whole tone of this project: this is a
*first* release. I would be genuinely surprised if there weren't at least a
hundred bugs hiding in here somewhere. Rough edges, sharp corners, things that
work on my machine and nowhere else — all of that is on the table. **0.1.0 is a
starting line, not a finish line.**

But it runs. You can install it today, point it at a model you bring yourself,
and give AI a *place* to actually do the work — documents, sheets, canvas,
boards, agents that stick around for hours. That's the thing I set out to
build, and as of today it has a version number.

So yes — there will be champagne tonight. 🥂

## Try it

- **[Get started](/getting-started)** — the Docker stack, a couple of commands, a few minutes.
- **[Bring your own model](/getting-started#bring-your-own-model)** — Vancetope ships no model; you connect your own.
- Found one of those hundred bugs? Head to **[Discussions](https://github.com/mhus/vance/discussions)** or open an issue — that's exactly what the 0.1.x line is for.

Onward to 0.2. 🚀

  (function () {
    if (typeof window.confetti !== 'function') return;

      var end = Date.now() + 900;
      confetti({ particleCount: 140, spread: 75, startVelocity: 45, origin: { y: 0.6 } });

        confetti({ particleCount: 5, angle: 60, spread: 55, origin: { x: 0 } });

      })();
    }

    if (!reduce) window.addEventListener('load', rain);

    var again = document.getElementById('confetti-again');
    if (again) {
      again.addEventListener('click', function (e) {
        e.preventDefault();
        rain();
      });
    }
  })();
