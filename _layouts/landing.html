A personal project · not a product

A brain you shape from the inside.

Vance is a server where LLM agents pick up assignments and work them over hours and days. Recipes, prompts, schedulers, hooks — almost everything is a document in the database, so you and the agents can reshape the system without touching code.

What makes it tick

Four ideas do most of the work.

Everything else is a consequence of these.

01

Everything is a document

Recipes, prompts, schedulers, hooks, manuals, settings — all stored in MongoDB. A new automation is a new document. The system reshapes itself from its own data, and so can agents.

02

Agents drive (almost) everything

Nearly every capability is a tool: write documents, spawn processes, set triggers, research, delegate. You give the direction and step in whenever you want — the flow stays visible.

03

Projects draw the boundaries

A project is a bounded area with its own documents, config and agents. Different setups live side by side. Memory and permissions inherit down a scope cascade.

04

Built to work in, together

Cortex unites chat, documents and execute on one surface — live-edited with other people and with agents in the same session. Presence, merge and versioning included.

The crew

A handful of engines. Many recipes.

Engines are Java algorithms with a lifecycle — code drives the flow, not the LLM. Which one runs is decided by a recipe (a YAML document), so a new kind of assignment needs no new code. Yes, they’re named after the Guide.

One brain, many ways in

Meet it where you work.

The Brain is the single source of truth. Clients are different entry points into the same project — not views on the same thing.

vance-foot

Terminal

Work right at the command line, with local tools (shell, files, git) — but always inside a project, with everything stored in it.

vance-face

Web

The working environment in the browser: chat, live documents in many kinds, and apps built on top of them.

vance-facelift

Mobile

On the go — a wrapper around the deployed Web UI, with an isolated WebView per account.

Honest bit

It’s a personal project.

I built Vance to develop LLM agents and shape them until I could actually work productively with them. Over time everything I found interesting went in — plus a few things I think others might get something out of.

It’s not for sale. No support contract, no roadmap promises. The code is open because it might be useful to you. Poke around, build on it, steal ideas.

— Mike Hummel
